# フーリエ変換・畳み込みと数え上げ

この機能群は通常テンプレートと別枠です。必要になったときに次を読み込めます。

```cpp
#include "library/convolution/all.hpp"
```

単一ファイルで使う場合はリポジトリ直下の `convolution_template.cpp` を使ってください。
`library/all.hpp` と通常の `template.cpp` には、この追加パックを含めていません。
既存のmod付きNTTは従来どおり通常ライブラリから利用できます。

## 最初に覚えること

畳み込みは、配列 `a`, `b` から `c[s] = Σ a[i] * b[s-i]` をまとめて求める操作です。
多項式の掛け算と同じで、要素数が `n`, `m` なら結果は `n+m-1` 要素です。
空の配列を含む場合は空配列を返します。

二重ループなら `O(nm)`。FFTやNTTを使うと、必要な長さを2の冪に切り上げた `L` に対して `O(L log L)` で計算できます。
小さい配列では変換の準備がかえって重いため、実装は単純な掛け算も使い分けます。

数え上げで大切なのは、配列の**添字を値、要素をその値の個数**にすることです。
たとえば `{1,1,2}` の度数配列は `{0,2,1}` です。
度数配列を掛け合わせると、和が同じになる選び方が同じ添字に集まります。

## 目的別の入口

追加パックの関数名には `cp_transform::` を付けます。既存のmod付き関数は従来どおりです。

| やりたいこと | 関数 | 結果・注意 |
|---|---|---|
| 998244353で多項式を掛ける | `convolution(vector<mint>, vector<mint>)` | 正確なmod付き計算 |
| 同じ多項式を二乗する | `convolution_square(a)` | NTTを3回から2回に削減 |
| 整数の答えをそのまま求める | `cp_transform::convolution_ll(a,b)` | `vector<long long>`、範囲検査あり |
| 1e9+7など任意のmodで掛ける | `cp_transform::convolution_mod(a,b,modulus)` | `vector<int>`、合成数のmodも可 |
| 実数の多項式を掛ける | `cp_transform::convolution_real(a,b)` | `vector<long double>`、近似計算 |
| 変換自体を学ぶ | `cp_transform::fft(a, inverse)` | `vector<complex<long double>>` |
| Aから1個、Bから1個選んだ和 | `cp_transform::pair_sum_counts(A,B)` | 各和を作る添字ペアの個数 |
| 同じ配列から異なる2要素を選ぶ | `cp_transform::unordered_pair_sum_counts(A)` | `i<j` の個数 |
| 選択をK回繰り返した和 | `cp_transform::sum_distribution_mod(ways,K,S)` | 和0〜Sの個数、998244353 |

## 例1：2つの配列から選んだ和

```cpp
vector<int> a{1, 1, 2}, b{0, 2};
auto count = cp_transform::pair_sum_counts(a, b);
cout << count[3] << '\n'; // 2
```

和3は「aの1とbの2」で作れます。aに1が2個あるので答えは2です。
同じ値でも添字が違えば別の選び方として数えます。入力値は非負整数に限ります。

## 例2：同じ配列から2つ選ぶ

```cpp
auto count = cp_transform::unordered_pair_sum_counts({1, 1, 2});
cout << count[2] << ' ' << count[3] << '\n'; // 1 2
```

この関数は異なる添字の組 `i<j` を数えます。
単に度数配列を二乗すると `(i,j)` と `(j,i)`、さらに `(i,i)` まで数えてしまいます。
そこで同じ添字の分を除き、最後に2で割ります。「同じ値の要素を2つ選ぶ」のは許されます。

## 例3：サイコロや繰り返し選択

```cpp
vector<long long> ways{0, 1, 1}; // 1を選ぶ方法が1通り、2を選ぶ方法が1通り
auto count = cp_transform::sum_distribution_mod(ways, 2, 4);
cout << count[2] << ' ' << count[3] << ' ' << count[4] << '\n'; // 1 2 1
```

「1または2を、戻しながら2回選ぶ」場合です。`(1,2)` と `(2,1)` を別々に数えます。
一般には `F(x)=Σ ways[v] x^v` の `K` 乗を求めます。
二分累乗を使い、和Sを超える項は途中で捨て、二乗には専用の変換再利用処理を使います。
計算量の上限は `O(L log L log K)`、使用メモリは `O(L)` です。

戻り値は常に `S+1` 要素です。K=0なら和0だけ1通り、K>0で選択肢が空ならすべて0です。
これは「順序を区別しない選び方」や「各要素を1回まで使う部分集合」の数え上げとは別の問題です。

## FFTと整数の正確さ

FFTは複素数で変換するため丸め誤差があります。`fft` は順変換に負の指数を使い、逆変換では長さで割ります。
`fft` の入力長は2の冪にし、必要なら0で埋めます。空配列は何もしません。
`convolution_real` が長さの調整と変換・逆変換をまとめて行います。

整数の数え上げでは、FFTの結果を丸める方法を使いません。
`convolution_ll` と `convolution_mod` は3つの素数でNTTを行い、中国剰余定理で復元します。
998244353だけでよい場合は、既存の `convolution` のほうが変換回数が少なく済みます。

## 入力範囲

| 機能 | 制約 |
|---|---|
| FFT / 実数畳み込み | 0埋め後の長さが `2^23` 以下。結果は近似値 |
| 整数 / 任意mod畳み込み | 結果の長さが `2^24` 以下 |
| 整数畳み込み | 全係数が `long long` に収まること。後述の復元範囲も必要 |
| 任意mod畳み込み | `1 <= modulus <= INT_MAX`。負の入力も可 |
| ペアの和 | 非負整数、密な度数配列の結果長が `2^24` 以下。中間の個数も `long long` の範囲内 |
| 繰り返し選択 | `ways[v]>=0`, `K>=0`, `0<=S<2^22` |

整数畳み込みでは、3素数の積をPとして、通常は
`min(n,m) * maxabs(a) * maxabs(b) <= floor(P/2)` を要求します。
この検査は安全側なので、打ち消し合って最終結果が小さくなる入力も範囲外として拒否する場合があります。
片方が1要素なら128bitで直接計算します。
復元範囲外や結果のオーバーフローは `overflow_error`、長さ超過は `length_error`、不正な引数は `invalid_argument` になります。

度数配列を使うので、たとえば値が10億で要素数が10個しかない入力には向きません。
和を保たない通常の座標圧縮では置き換えられないため、その場合は二重ループなどを検討してください。

## 履修の順番

1. 度数配列の二重ループで、添字が和になることを確かめる。
2. `convolution(vector<mint>, ...)` で同じ計算を置き換える。
3. 複素数のFFTと、mod上のNTTが多項式の掛け算を速くする仕組みを学ぶ。
4. 多項式の累乗を、サイコロや繰り返し選択の数え上げに使う。

実行できる例は `examples/convolution_counting.cpp`、小さな全探索との比較は `tests/fourier_counting_test.cpp` にあります。
